# Основы работы с системой управления версиями Git
Цель лабораторной работы: изучить назначение распределённой системы управления версиями, освоить процесс создания репозитория и основы управления версиями файлов.

Участники: Луканин Д.А.

Команды git:
git init - инициализация репозитория
git clone <url> - клонирование репозитория
git add <file> - добавление изменения файла в индекс для последующего коммита
git add . - подготовка к коммиту всех файлов
git commit -m "<text>" - коммит с комментарием
git rm <file> - удаление файла из индекса
git push - отправка изменений в удалённый репозиторий
git pull - получение изменений из удалённого репозитория
git remote - просмотр удалённых репозиториев
git remote -v - просмотр удалённых URL-адресов репозиториев
git checkout <branch_name> - переключение на указанную ветку
